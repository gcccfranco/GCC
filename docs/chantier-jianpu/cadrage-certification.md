# Certification du recadrage 简谱 (lot 3, L3-T1)

Registre des valeurs `top` (première page de chaque scan) certifiées à l'œil dans `public/jianpu/cadrage.json`.
Règle : une valeur n'y entre qu'après lecture de la planche `audit-browser.ts <slug> --cadrage` (ligne rouge, partie coupée voilée).
Critères : la ligne passe au-dessus de « 1=X 4/4 » (et de tout accord au-dessus) sans trancher un glyphe ; titre, album, versets
sont coupés quand une coupe propre existe ; ce qui reste faute de coupe propre (crédits sur la même ligne) est accepté.
Verdicts : accepté (proposition gardée), corrigé (valeur posée à la main), sans coupe propre (en-tête gardé).
