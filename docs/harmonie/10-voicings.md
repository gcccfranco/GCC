# 10 · Voicings

**Le même accord, un autre son.** On ne change pas les accords : on change la
façon de les jouer (quelles notes, où, dans quel ordre). Ces fiches sont
**propres à un instrument** : V1 à V3 pour le piano, V4 à V6 pour la guitare.
Elles vivent dans le catalogue seulement (pas de suggestion par chant).

Tout est écrit en D.

---

## V1 · Piano : ouvrir l'accord

| | |
| --- | --- |
| Id | `voicings/piano-ouvrir` |
| Statut | à valider |
| Instrument | piano |
| Sensations | Majesté · Épique · Lumière et espérance |
| Moments | Refrain |
| Niveau | facile |

**Avant → après** : main gauche D-F#-A serrée dans le grave, main droite D-F#-A
devient main gauche **D-A-D** (quinte et octave), main droite **F#-A-D** au
milieu du clavier.

**Pourquoi ça marche.** Dans le grave, la tierce (F#) sonne « boueuse » : les
notes proches se mélangent. Quinte et octave donnent un socle large et clair ;
la main droite porte la couleur (la tierce) là où elle s'entend bien. Le même
accord sonne deux fois plus grand.

**Quand l'éviter.**
- Sur un couplet intime : une seule note grave à la main gauche suffit. Garder
  la quinte-octave pour le refrain, c'est aussi créer une montée.
- Si un bassiste joue : lui laisser le grave, rester au-dessus.

**Au piano.** Couplet : main gauche D seule, main droite F#-A-D. Refrain : main
gauche D-A-D, main droite F#-A-D une octave plus haut.

**Règle.** Aucune : catalogue seul.

## V2 · Piano : garder les notes communes

| | |
| --- | --- |
| Id | `voicings/piano-notes-communes` |
| Statut | à valider |
| Instrument | piano |
| Sensations | Douceur et intimité · Repos |
| Moments | Couplet · Refrain |
| Niveau | facile |

**Avant → après** : `D – A – Bm – G` joués tous en position fondamentale (la
main droite saute) devient, à la main droite :
`F#-A-D → E-A-C# → F#-B-D → G-B-D`.

**Pourquoi ça marche.** Chaque accord garde les notes qu'il partage avec le
précédent, et les autres bougent **d'un ton au plus**. Le son devient lié,
comme un chœur qui chante les accords, et la voix des chanteurs ressort au
lieu d'être couverte par des sauts.

**Quand l'éviter.**
- Quand la main droite descend trop bas à force de glisser : remonter d'une
  octave au début d'une nouvelle section.

**Au piano.** Choisis la position du premier accord en fonction de la
mélodie (reste sous la voix), puis ne bouge que les doigts nécessaires.

**Règle.** Aucune : catalogue seul.

## V3 · Piano : jouer 3 et 7

| | |
| --- | --- |
| Id | `voicings/piano-3-et-7` |
| Statut | à valider |
| Instrument | piano |
| Sensations | Douceur et intimité · Suspendu et planant |
| Moments | Couplet · Pont |
| Niveau | intermédiaire |

**Avant → après** : `Em7 – A7` joués avec toutes les notes devient main
gauche **E**, main droite **G-D** ; puis main gauche **A**, main droite
**G-C#**.

**Pourquoi ça marche.** Dans un accord de septième, la **tierce** dit majeur
ou mineur, la **septième** dit la couleur. La quinte n'apporte presque rien et
encombre. Avec 3 et 7 seulement, l'accord est riche mais léger. Et d'un accord
à l'autre, ces notes bougent à peine (D → C#, G reste).

**Quand l'éviter.**
- Sur des accords sans septième (D, G) : garder la tierce et la quinte.

**Au piano.** Ajoute la neuvième si tu veux plus de couleur : F# sur Em7
(G-D-F#), B sur A7 (G-B-C#).

**Règle.** Aucune : catalogue seul.

## V4 · Guitare : les cordes à vide qui sonnent

| | |
| --- | --- |
| Id | `voicings/guitare-cordes-a-vide` |
| Statut | à valider |
| Instrument | guitare |
| Sensations | Lumière et espérance · Suspendu et planant |
| Moments | Intro · Couplet · Refrain |
| Niveau | facile |

**Avant → après** : les formes barrées ou « de base » deviennent des formes
ouvertes qui laissent sonner les cordes à vide. En D : D `xx0232`, Dsus2
`xx0230`, G `320033`, Em7 `022033`, Asus4 `x02230`, Bm7 `x20202`.

**Pourquoi ça marche.** Les cordes à vide résonnent plus longtemps que les
cordes appuyées : le son est ample, brillant, et des notes communes continuent
de sonner d'un accord à l'autre, surtout sur les cordes aiguës. G `320033` et
Em7 `022033` gardent même deux doigts fixes en 3e case.

**Quand l'éviter.**
- Dans une tonalité où les cordes à vide ne sont pas dans la gamme (Eb, Ab) :
  mettre un capo (V6).

**À la guitare.** Enchaîne G `320033` – Em7 `022033` – Asus4 `x02230` – D
`xx0232` en gardant les doigts qui ne bougent pas.

**Règle.** Aucune : catalogue seul.

## V5 · Guitare : les triades en haut du manche

| | |
| --- | --- |
| Id | `voicings/guitare-triades-aigues` |
| Statut | à valider |
| Instrument | guitare |
| Sensations | Lumière et espérance · Douceur et intimité |
| Moments | Couplet · Pont |
| Niveau | intermédiaire |

**Avant → après** : les accords sur six cordes deviennent **trois notes sur
les cordes aiguës** (sol, si, mi) : D `xxx775`, G `xxx433`, A `xxx655`, Bm
`xxx432`.

**Pourquoi ça marche.** Le piano occupe déjà le grave et le médium. En
jouant seulement dans l'aigu, la guitare brille au-dessus au lieu de doubler
le piano : on entend mieux les deux.

**Quand l'éviter.**
- Quand la guitare est seule : il lui faut alors le grave.

**À la guitare.** Rythmique légère ou arpèges ; les petites formes permettent
de glisser d'un accord à l'autre le long du manche.

**Règle.** Aucune : catalogue seul.

## V6 · Guitare : capo et formes pour changer de couleur

| | |
| --- | --- |
| Id | `voicings/guitare-capo-couleur` |
| Statut | à valider |
| Instrument | guitare |
| Sensations | Lumière et espérance · Émerveillement |
| Moments | Intro · Couplet · Refrain |
| Niveau | facile |

**Avant → après** : chant en D joué en formes de D sans capo devient, **dans
la même tonalité** : capo 2 et formes de C, capo 5 et formes de A, ou capo 7
et formes de G.

**Pourquoi ça marche.** Les formes ouvertes ne sonnent pas pareil : formes de
C plus rondes, formes de G plus brillantes, et capo haut plus cristallin. Même
tonalité, autre timbre. Avec deux guitares, l'une sans capo et l'autre capo 7,
le son s'élargit.

**Quand l'éviter.**
- Capo très haut (7 et plus) sur un chant qui a besoin de grave.

**À la guitare.** Dans l'app, le réglage capo transforme les accords et les
diagrammes en formes : choisis le capo, lis les formes.

**Règle.** Aucune : catalogue seul.
