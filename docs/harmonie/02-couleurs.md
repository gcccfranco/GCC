# 02 · Couleurs

On **ajoute ou on déplace une note** dans l'accord, sans changer sa fonction :
D reste D, mais il sonne plus ouvert, plus doux ou plus riche.

Tout est écrit en D. Degrés en chiffres (voir `README.md`).

---

## C1 · L'accord « 2 » (add9)

| | |
| --- | --- |
| Id | `couleurs/accord-2` |
| Statut | à valider |
| Sensations | Lumière et espérance · Suspendu et planant |
| Moments | Intro · Couplet · Refrain |
| Niveau | piano : facile · guitare : intermédiaire |

**Avant → après** : `D` devient `D2` (Dadd9) · degrés `1` devient `1 2`
(de même `4` devient `4 2` : G2).

**Pourquoi ça marche.** On ajoute E à D-F#-A. E est à un ton de D et de F# :
un frottement doux, jamais dur. L'accord garde sa tierce (F#), donc reste
clairement majeur, mais il sonne ouvert, « moderne ». C'est la couleur la plus
utilisée en louange.

**Quand l'éviter.**
- Sur le 5 qui doit pousser vers le 1 : A2 adoucit la tension.
- Quand l'autre instrument la joue déjà : si la guitare fait D2, le piano peut
  garder D simple, pour ne pas empiler les frottements.

**Au piano.** Main droite F#-A-E ou A-D-E : mets le E **en haut**, jamais collé
au D tout en bas. Main gauche : D.

**À la guitare.** Attention : le « D2 » des grilles se joue souvent `xx0230`,
qui est en fait un **Dsus2** (sans F#, voir C3). Le vrai Dadd9 : `x54230`. Pour
G2 : `320203` ; pour C2 : `x32033`.

**Dans le répertoire** (`1 2` : 14 chants, `4 2` : 29 chants) : *Ébloui*
(couplet : D2) · *Nous tiendrons* (refrain, en F : F2 « Les yeux fixés sur
Toi ») · *Quand je contemple* (couplet, en C : C2) · *À la croix* (couplet, en
E : A2) · 奇异恩典 (主歌, en E : E2) · 你是我的平安 (桥段 : Gadd9).

**Règle.** Portée : Intro, Refrain · motif `1` ou `4` sans couleur · remplacement
`1 2` ou `4 2` · sûreté : **très sûre**.

## C2 · Le sus4 qui se résout

| | |
| --- | --- |
| Id | `couleurs/sus4-resolu` |
| Statut | à valider |
| Sensations | Tension · Repos |
| Moments | Montée · Refrain · Fin |
| Niveau | piano : facile · guitare : facile |

**Avant → après** : `A → D` devient `Asus4 – A → D` · degrés `5 → 1` devient
`5sus4 – 5 → 1`.

**Pourquoi ça marche.** Asus4 remplace la tierce C# par D : l'accord n'est ni
majeur ni mineur, il attend. Quand D redescend sur C#, la tension se relâche :
un petit soupir juste avant le repos.

**Quand l'éviter.**
- Quand la mélodie chante C# pendant le sus4 : C# contre D frotte.
- Sur tous les 5 du chant : l'effet s'use vite. Une ou deux fois, aux fins de
  phrase importantes.

**Au piano.** Main droite A-D-E puis A-C#-E : un seul doigt descend. Main
gauche : A, tenu.

**À la guitare.** Asus4 `x02230` puis A `x02220` : un doigt descend d'une case
sur la corde de si. En D : Dsus4 `xx0233` puis D `xx0232`.

**Dans le répertoire** (`5sus4 → 5` : 67 chants, 33 fr, 34 zh) : *Bénis Dieu
(10000 raisons)* (refrain : « Magnifie Son saint Nom », Asus4 – A) · *Ta
parole* (couplet, en Bb : « pour te contempler », Fsus4 – F) · *À la croix*
(couplet, en E : Bsus4 – B) · 一粒麦子 (副歌, en F : Csus4 – C) · 一生爱你
(主歌, en E : Bsus4 – B).

**Règle.** Portée : fin de ligne · motif `5 → 1` · remplacement
`5sus4 – 5 → 1` · sûreté : **sûre**.

## C3 · Le sus2, ouvert et flottant

| | |
| --- | --- |
| Id | `couleurs/sus2` |
| Statut | à valider |
| Sensations | Suspendu et planant · Émerveillement |
| Moments | Intro · Couplet · Pont |
| Niveau | piano : facile · guitare : facile |

**Avant → après** : `D` devient `Dsus2` · degrés `1` devient `1sus2`.

**Pourquoi ça marche.** Dsus2 remplace la tierce F# par E. Or c'est la tierce
qui dit « majeur » ou « mineur » : sans elle, l'accord n'a plus de caractère,
il flotte. Différence avec C1 : le « 2 » **garde** F# (lumineux), le sus2
**l'enlève** (neutre, spacieux).

**Quand l'éviter.**
- Quand le passage doit sonner franchement joyeux ou franchement grave : le
  sus2 efface ce caractère.
- Trop longtemps : on finit par ne plus savoir dans quelle tonalité on est.

**Au piano.** Main droite D-E-A (ou A-D-E). Main gauche : D, ou D-A.

**À la guitare.** Dsus2 `xx0230` ; Asus2 `x02200`.

**Dans le répertoire** (sus2 écrit : 2 chants ; beaucoup de « D2 » de guitare
sont en fait joués sus2) : *Lumière du monde* (couplet : « Tu m'ouvres les
yeux », Gsus2) · *Viens toucher ma vie* (couplet, en A : Dsus2).

**Règle.** Portée : Intro, Pont · motif `1` tenu · remplacement `1sus2` ·
sûreté : **sûre**.

## C4 · Le maj7 sur le 1 et le 4

| | |
| --- | --- |
| Id | `couleurs/maj7` |
| Statut | à valider |
| Sensations | Douceur et intimité · Tendresse et nostalgie |
| Moments | Couplet · Pont · Intro |
| Niveau | piano : facile · guitare : facile |

**Avant → après** : `G` devient `Gmaj7`, `D` devient `Dmaj7` · degrés `4`
devient `4maj7`, `1` devient `1maj7`.

**Pourquoi ça marche.** On ajoute la septième majeure, un demi-ton sous la
fondamentale (F# sous G, C# sous D). Ce frottement très doux donne un son
feutré, « velours ».

**Quand l'éviter.**
- **Sur le 1 quand la mélodie chante D** en valeur longue : D contre C#
  frotte. C'est fréquent, d'où « à écouter » sur le 1.
- Sur un refrain triomphant : le maj7 adoucit trop.
- **Jamais sur le 5** : Amaj7 contient G#, hors de la gamme de D.

**Au piano.** Main droite F#-A-C# (pas de D en haut, collé au C#). Main
gauche : D. Pour Gmaj7 : main droite B-D-F#, main gauche G.

**À la guitare.** Dmaj7 `xx0222` ; Gmaj7 `320002` ; Cmaj7 `x32000`.

**Dans le répertoire** (`4maj7` : 36 chants, `1maj7` : 18 chants) : *Il
m'aime* (refrain, en G : CM7 « Il m'aime ») · *Le Fils de Dieu* (couplet :
GM7, puis DM7 « pour toujours ») · *Quand je contemple* (refrain, en C : FM7
« Oh ! Je T'adore ») · *Jireh* (intro : Gmaj7) · 一切都更新 (主歌, en C :
Cmaj7) · 你是我的平安 (前奏 : Dmaj7).

**Règle.** Portée : Couplet, Pont · motif `4` · remplacement `4maj7` · sûreté :
**sûre** (sur le `1` : **à écouter**).

## C5 · Le 6 et le 6/9

| | |
| --- | --- |
| Id | `couleurs/6-et-6-9` |
| Statut | à valider |
| Sensations | Joie et élan · Lumière et espérance · Émerveillement |
| Moments | Fin · Intro |
| Niveau | piano : intermédiaire · guitare : intermédiaire |

**Avant → après** : `D` devient `D6` ou `D6/9` · degrés `1` devient `1 6`
ou `1 6/9`.

**Pourquoi ça marche.** La sixte (B sur D) ajoute de la chaleur sans aucune
tension. Avec la neuvième en plus (E), le 6/9 est très riche mais parfaitement
stable : un accord de fin qui brille, qui ne demande rien.

**Quand l'éviter.**
- Sur un moment grave (croix, repentance) : le 6 sonne léger, presque jazz.
- Si la basse joue B : D6 avec B en bas devient Bm7, un autre accord.

**Au piano.** D6/9 : main gauche D-A, main droite F#-B-E (ou B-E-F#).

**À la guitare.** D6 `xx0202` ; D6/9 `x5445x` ; G6 `320000`.

**Dans le répertoire** (6 chants) : *Jireh* (interlude : G6) · *Cherchez
d'abord* (« Alléluia » : A6) · *De tout mon être* (intro, en E : B6) · 深深爱你
(主歌, en E : A6) · 一生爱你 (前奏, en E : A6/E).

**Règle.** Portée : dernière occurrence, toute fin du chant · motif `1` final ·
remplacement `1 6/9` · sûreté : **sûre**.

## C6 · Le m7 sur les accords mineurs

| | |
| --- | --- |
| Id | `couleurs/m7` |
| Statut | à valider |
| Sensations | Douceur et intimité · Suspendu et planant |
| Moments | Couplet · Refrain |
| Niveau | piano : facile · guitare : facile |

**Avant → après** : `Bm` devient `Bm7`, `Em` devient `Em7` · degrés `6m`
devient `6m7`, `2m` devient `2m7`.

**Pourquoi ça marche.** La septième (A sur Bm, D sur Em) est une note de la
gamme, déjà dans l'air : l'accord mineur perd sa dureté et devient souple. Bm7
(B-D-F#-A) contient même **tout l'accord de D** : c'est pour ça qu'il sonne si
naturel dans un chant en D.

**Quand l'éviter.**
- Quand le mineur doit rester sombre (texte de deuil, de lutte) : le m7 le
  rend presque doux.

**Au piano.** Astuce : Bm7 = **l'accord de D (main droite) avec B à la main
gauche**. Em7 = accord de G avec E à la main gauche.

**À la guitare.** Bm7 `x20202` ; Em7 `022033` ou `020000` ; F#m7 `242222`.

**Dans le répertoire** (`6m7` : 92 chants, `2m7` : 95 chants) : *Ce Nom si
merveilleux* (couplet : Bm7 « Fils unique du Dieu très-haut ») · *Béni soit Ton
Nom* (couplet, en A : F#m7) · *Amour parfait* (refrain, en C : Am7) · *Au nom
de Jésus* (couplet : Em7) · 一颗谦卑的心 (主歌 : Bm9) · 为爱而生 (预备, en E :
C#m7).

**Règle.** Portée : dans une section · motif `6m` ou `2m` · remplacement `6m7`
ou `2m7` · sûreté : **très sûre**.

## C7 · Le 4 lydien (4maj7#11)

| | |
| --- | --- |
| Id | `couleurs/4-lydien` |
| Statut | à valider |
| Sensations | Émerveillement · Suspendu et planant |
| Moments | Pont · Intro |
| Niveau | piano : intermédiaire · guitare : intermédiaire |

**Avant → après** : `G` (tenu) devient `A/G` · degrés `4` devient `5/4`
(un 4 lydien).

**Pourquoi ça marche.** Sur G, on fait entendre C#, une note de la gamme de D
qui sonne « au-delà » de l'accord de G : lumineux, céleste, suspendu. C'est le
son des musiques de film pour l'émerveillement. A/G joue exactement ça : les
notes de A (A-C#-E) posées sur G.

**Quand l'éviter.**
- Quand la mélodie chante C naturel (rare en D) : il frotte contre le C#.
- Sur un passage où l'on veut un 4 franc et simple.

Pourquoi A/G plutôt que Gmaj7(#11) : A/G n'a pas de F#, donc ne frotte pas
avec une mélodie qui tient G.

**Au piano.** Main gauche : G (ou G-D). Main droite : l'accord de A (A-C#-E).

**À la guitare.** A/G `3x2220`.

**Dans le répertoire** : même son que M3 (« Le 4 – 5/4 qui soulève »), dans 45
chants, par exemple *Quand je contemple* (refrain, en C : FM7 – G/F).

**Règle.** Aucune : c'est M3 qui propose ce son sur un chant, en mouvement.
