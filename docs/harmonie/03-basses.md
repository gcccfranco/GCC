# 03 · Basses

On garde presque les mêmes accords, mais **la basse raconte quelque chose** :
elle descend, elle monte, ou elle reste immobile pendant que tout bouge
au-dessus. Au piano, c'est la main gauche ; à la guitare, la corde grave (pouce).

Tout est écrit en D. `1/3` = accord du 1 avec la tierce à la basse (D/F#).

---

## B1 · La basse qui descend

| | |
| --- | --- |
| Id | `basses/descend` |
| Statut | à valider |
| Sensations | Douceur et intimité · Tendresse et nostalgie |
| Moments | Couplet · Intro |
| Niveau | piano : facile · guitare : intermédiaire |

**Avant → après** : `D → Bm → G` devient `D – A/C# – Bm – Bm/A – G` · degrés
`1 → 6m → 4` devient `1 – 5/7 – 6m – 6m/5 – 4`.

**Pourquoi ça marche.** La basse descend note par note : D, C#, B, A, G. Les
accords au-dessus changent à peine. L'oreille suit cette ligne comme une
deuxième mélodie, en dessous : le passage devient fluide, comme une pente
douce.

**Quand l'éviter.**
- Si la mélodie tient D pendant A/C# : D contre C# frotte. Joue alors **D/C#**
  (l'accord de D sur C#).
- Si la basse doit rester sur D (pédale voulue, voir B5).

**Au piano.** Main gauche : D – C# – B – A – G, une note par accord. Main
droite : des accords proches, qui bougent le moins possible.

**À la guitare.** A/C# `x42220` ; D/C# `x4x232` ; Bm/A `x0x432`. Le pouce
fait la descente.

**Dans le répertoire** (basse `1 – 7 – 6` : 133 chants, 24 fr, 109 zh) :
*Bénis Dieu (10000 raisons)* (refrain : D – A/C# – Bm) · *À la croix* (refrain,
en E : E – B/D# – C#m « À la croix je me prosterne ») · *Abrite-moi* (couplet,
en C : C – G/B – Am) · *Au dessus de tout* (couplet, en A : A – A/G# – F#m) ·
一粒麦子 (主歌, en F : F – C/E – Dm) · 一生跟随 (前奏, en F : F – C/E – Dm).

**Règle.** Portée : dans une section · motif `1 → 6m` · remplacement
`1 – 5/7 → 6m` · sûreté : **sûre**.

## B2 · La basse qui monte

| | |
| --- | --- |
| Id | `basses/monte` |
| Statut | à valider |
| Sensations | Joie et élan · Lumière et espérance |
| Moments | Montée · Refrain |
| Niveau | piano : facile · guitare : facile |

**Avant → après** : `G → Bm` devient `G – A – Bm` · degrés `4 → 6m` devient
`4 – 5 – 6m`.

**Pourquoi ça marche.** Un saut de basse (G → B) devient une marche : G, A,
B. Chaque accord pousse le suivant, l'énergie monte.

**Quand l'éviter.**
- Quand la mélodie tient D pendant le A ajouté : D frotte contre C#.
- Sur un tempo très rapide : l'accord ajouté n'a pas le temps d'exister.

**Au piano.** Main gauche : G – A – B. Main droite : place le A sur la
deuxième moitié de la mesure de G.

**À la guitare.** G `320033` – A `x02220` – Bm7 `x20202` : garde une
rythmique régulière, le A arrive sur les derniers temps.

**Dans le répertoire** (`4 – 5 – 6m` : 64 chants, 53 fr, 11 zh) : *Amour sans
fin* (pré-refrain : G – A – Bm) · *Ta parole* (refrain, en Bb : Eb – F – Gm) ·
*Abba Père* (refrain, en A : D – E – F#m « Abba Père, je suis à Toi ») ·
*Abrite-moi* (refrain, en C : F – G – Am) · 你坐着为王 (副歌, en F : Bb – C –
Dm) · 使命 (主歌, en A : D – E – F#m).

**Règle.** Portée : dans une section · motif `4 → 6m` · remplacement
`4 – 5 → 6m` · sûreté : **à écouter**.

## B3 · Le 1 sur 3 pour relier

| | |
| --- | --- |
| Id | `basses/1-sur-3` |
| Statut | à valider |
| Sensations | Joie et élan · Lumière et espérance |
| Moments | Couplet · Montée |
| Niveau | piano : facile · guitare : facile |

**Avant → après** : `D → G` devient `D – D/F# → G` · degrés `1 → 4` devient
`1 – 1/3 → 4`.

**Pourquoi ça marche.** D/F# est **le même accord** que D, seule la basse
change : D → F# → G. Le saut de basse devient une montée, et F# → G, un
demi-ton, tire fort vers G. Aucun risque avec la mélodie.

**Quand l'éviter.**
- Presque jamais. Seulement si la basse joue déjà une ligne écrite différente.

**Au piano.** Main droite : D, tenu. Main gauche : D puis F#, puis G.

**À la guitare.** D/F# `2x0232` : le pouce sur la corde de mi grave, 2e case.

**Dans le répertoire** (`1/3 → 4` : 128 chants, 63 fr, 65 zh) : *Au nom de
Jésus* (instrumental : D/F# – G) · *Abrite-moi* (couplet, en C : C/E – F
« Couvre-moi par Ta main puissante ») · *Au dessus de tout* (refrain, en A :
A/C# – D2) · 一切歌颂赞美 (主歌, en E : E/G# – A) · 一生敬拜你 (导歌, en C :
C/E – F).

**Règle.** Portée : dans une section · motif `1 → 4` · remplacement
`1 – 1/3 → 4` · sûreté : **très sûre**.

## B4 · Le 5 sur 7 vers le 1

| | |
| --- | --- |
| Id | `basses/5-sur-7` |
| Statut | à valider |
| Sensations | Repos · Joie et élan |
| Moments | Couplet · Refrain · Fin |
| Niveau | piano : facile · guitare : intermédiaire |

**Avant → après** : `A → D` devient `A/C# → D` · degrés `5 → 1` devient
`5/7 → 1`.

**Pourquoi ça marche.** C#, la sensible, passe à la basse et monte d'un
demi-ton sur D. Le retour au 1 est plus lié, plus chantant qu'un saut A → D.

**Quand l'éviter.**
- Quand la mélodie tient D pendant A/C# (D contre C# à la basse, dur).
- Sur la toute dernière cadence, si l'on veut un final franc : A → D, basse
  qui saute, est plus affirmé.

**Au piano.** Main gauche : C# puis D. Main droite : A-C#-E ou C#-E-A, puis D.

**À la guitare.** A/C# `x42220`, puis D `xx0232`.

**Dans le répertoire** (`5/7 → 1` : 42 chants, 21 fr, 21 zh) : *Ta parole*
(refrain, en Bb : F/A – Bb « pour révéler le Christ ») · *Dieu est parmi nous*
(refrain, en G : D/F# – G) · *Christ est la lumière* (couplet, en C : G/B – C) ·
*Au dessus de tout* (couplet, en A : E/G# – A) · 医治我 (主歌, en A : E/G# – A)
· 一生敬拜你 (主歌, en C : G/B – C).

**Règle.** Portée : dans une section · motif `5 → 1` · remplacement
`5/7 → 1` · sûreté : **à écouter**.

## B5 · La pédale de 1

| | |
| --- | --- |
| Id | `basses/pedale-de-1` |
| Statut | à valider |
| Sensations | Repos · Suspendu et planant |
| Moments | Intro · Pont · Fin |
| Niveau | piano : facile · guitare : facile |

**Avant → après** : `D → G → D` devient `D – G/D – D` · degrés `1 → 4 → 1`
devient `1 – 4/1 – 1` (aussi `5/1`).

**Pourquoi ça marche.** La basse reste sur D pendant que les accords bougent
au-dessus : on sent le mouvement sans quitter la maison. C'est stable, ancré,
et ça laisse toute la place à la voix.

**Quand l'éviter.**
- A/D trop longtemps : son C# frotte contre le D de la basse. En passage
  seulement ; G/D, lui, peut durer.
- Sur un passage qui doit avancer : la pédale immobilise.

**Au piano.** Main gauche : D (ou octave D-D), tenue. Main droite : D, puis
G-B-D, puis D.

**À la guitare.** La corde de ré à vide sonne sous tout : G/D `xx0433`, A/D
`xx0220`, D `xx0232`.

**Dans le répertoire** (`4/1` : 45 chants ; `1 – 4/1 – 1` : 17 chants) :
*Bénis Dieu (10000 raisons)* (refrain : « Je louerai Ton saint Nom », D – G/D –
D) · *Je fléchis le genou* (refrain, en G : G – C/G – G) · *Je célèbrerai*
(couplet, en C : C – F/C – C) · *Hosanna (Ouvrons les portes)* (refrain : A/D)
· 哦十字架 (主歌, en F : F – Bb/F – F) · 一同齐声宣扬 (前奏, en A : D/A).

**Règle.** Portée : Intro, Pont · motif `1 → 4 → 1` · remplacement
`1 – 4/1 – 1` · sûreté : **sûre**.

## B6 · La basse chromatique

| | |
| --- | --- |
| Id | `basses/chromatique` |
| Statut | à valider |
| Sensations | Tendresse et nostalgie · Gravité et recueillement |
| Moments | Couplet · Pont |
| Niveau | piano : intermédiaire · guitare : intermédiaire |

**Avant → après** : `D → D → G` devient `D – D/C# – D/C – G/B` · degrés
`1 → 1 → 4` devient `1 – 1/7 – 1/b7 – 4/6`.

**Pourquoi ça marche.** La basse descend **demi-ton par demi-ton** (D, C#, C,
B) sous un accord qui ne bouge pas. D/C apporte une ombre (C naturel, hors
gamme), puis G/B retombe dans la lumière. Une émotion qui passe, puis
s'apaise.

**Variante** (fréquente dans nos chants chinois) : `D – A/C# – Am/C – G/B`.

**Quand l'éviter.**
- Quand la mélodie chante C# pendant D/C : frottement fort.
- Sur un tempo rapide : la descente ne s'entend plus.

**Au piano.** Main droite : D-F#-A, tenu. Main gauche : D – C# – C – B.

**À la guitare.** D `xx0232` – D/C# `x4x232` – D/C `x3x232` – G/B `x2003x`.

**Dans le répertoire** (basse `1 – 7 – b7` : 4 chants, tous en chinois) :
奔跑不放弃 (主歌, en E : E – B/D# – D) · 我渴望看见 (主歌, en F : F – C/E –
Cm/Eb) · 握住幸福 (前奏, en G : G – D/F# – Dm/F).

**Règle.** Portée : Couplet, Pont · motif `1 → 1 → 4` · remplacement
`1 – 1/7 – 1/b7 → 4/6` · sûreté : **à écouter**.
