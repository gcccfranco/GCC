# 06 · Montées

Ce qu'on joue **juste avant un refrain** (ou un moment fort) pour le faire
désirer : retenir, suspendre, faire monter la basse, ou se taire.

Tout est écrit en D.

---

## M1 · 2m7 – 4/5 avant le refrain

| | |
| --- | --- |
| Id | `montees/2m7-4-sur-5` |
| Statut | à valider |
| Sensations | Suspendu et planant · Tension |
| Moments | Montée |
| Niveau | piano : facile · guitare : intermédiaire |

**Avant → après** : `G → A` (fin de pré-refrain) devient `Em7 → G/A` ·
degrés `4 → 5` devient `2m7 → 4/5`.

**Pourquoi ça marche.** C'est S1 et S6 réunies. Em7 adoucit, G/A laisse la
tension en suspens sans la sensible (C#) : le refrain arrive comme une
respiration, pas comme un coup.

**Quand l'éviter.**
- Quand le refrain doit éclater : A (ou A7) pousse plus fort.
- Quand la mélodie chante C# sur la dernière syllabe avant le refrain.

**Au piano.** Main droite : G-B-D sur les deux accords. Main gauche : E, puis A.
Seule la main gauche bouge.

**À la guitare.** Em7 `022033` puis G/A `x00433`.

**Dans le répertoire** (`2m7 → 4/5` : 30 chants, 4 fr, 26 zh) : *Chantons*
(refrain, en A : Bm7 – D/E « Chantons car Dieu est là ») · *Bénis l'Éternel*
(refrain, en E : F#m7 – A/B) · *Auprès de Dieu* (couplet, en A : Bm7 – D/E) ·
*Le Fils de Dieu* (couplet : Em7 – G6/A) · 不停赞美你 (前奏, en G : Am7 – C/D)
· 为我而来 (桥段, en C : Dm7 – F/G).

**Règle.** Portée : fin de la section qui précède un refrain · motif `4 → 5`
ou `2m → 5` · remplacement `2m7 → 4/5` · sûreté : **à écouter**.

## M2 · Le 5sus4 tenu, puis 5

| | |
| --- | --- |
| Id | `montees/5sus4-tenu` |
| Statut | à valider |
| Sensations | Tension · Suspendu et planant |
| Moments | Montée |
| Niveau | piano : facile · guitare : facile |

**Avant → après** : `A` (dernier accord avant le refrain) devient
`Asus4 (tenu) → A` · degrés `5` devient `5sus4 → 5`.

**Pourquoi ça marche.** Tenir Asus4 retarde la résolution : tout le monde
attend. Passer à A au dernier moment, puis au refrain, libère d'un coup. Avec
un crescendo, c'est la montée la plus simple et la plus efficace.

**Différence avec C2** : C2 glisse le sus4 dans une phrase ; M2 le **tient**
à la frontière entre deux sections.

**Quand l'éviter.**
- Quand la mélodie chante C# pendant le sus4.
- Sans le batteur : la tenue doit se sentir aussi dans le rythme.

**Au piano.** Main droite : A-D-E, tenu, puis A-C#-E. Main gauche : A, en
octave pour la puissance.

**À la guitare.** Asus4 `x02230`, en accords plaqués ou en trémolo, puis A
`x02220`.

**Dans le répertoire** (`5sus4` en fin de section : 27 chants, 9 fr, 18 zh) :
*Dieu est parmi nous* (refrain, en G : Dsus4 « Il est parmi nous ») · *Ouvre
les yeux de mon cœur* (refrain, en E : Bsus) · *Libéré* (couplet, en G : Dsus4)
· 你是我的平安 (副歌 : Asus4) · 你的同在 (副歌 : Asus4) · 一切都更新 (副歌 1, en
C : Gsus4).

**Règle.** Portée : fin de la section qui précède un refrain · motif `5`
final · remplacement `5sus4 → 5` · sûreté : **sûre**.

## M3 · Le 4 – 5/4 qui soulève

| | |
| --- | --- |
| Id | `montees/4-5-sur-4` |
| Statut | à valider |
| Sensations | Émerveillement · Lumière et espérance · Joie et élan |
| Moments | Montée |
| Niveau | piano : facile · guitare : intermédiaire |

**Avant → après** : `G → A` devient `G → A/G` · degrés `4 → 5` devient
`4 → 5/4`.

**Pourquoi ça marche.** La basse reste sur G pendant que l'accord monte à A :
la tension monte sans que le sol bouge. A/G sonne lumineux (le « 4 lydien » de
C7), et le refrain qui suit libère.

**Quand l'éviter.**
- Quand la mélodie chante D en valeur longue pendant A/G : D contre C#.

**Au piano.** Main gauche : G, tenu. Main droite : G-B-D, puis A-C#-E.

**À la guitare.** G `320033` puis A/G `3x2220`.

**Dans le répertoire** (`4 → 5/4` : 45 chants, 5 fr, 40 zh) : *Quand je
contemple* (refrain, en C : FM7 – G/F « Oh ! Je T'adore ») · *Que tous soient
un* (couplet, en E : A – B/A) · *Seigneur, par la clarté* (couplet, en A : D –
E/D) · *Cherchez d'abord* (instrumental : G – A/G) · 为我而来 (副歌, en C :
Fmaj7 – G/F) · 一生敬拜你 (导歌, en C : F – G/F).

**Règle.** Portée : fin de la section qui précède un refrain · motif `4 → 5` ·
remplacement `4 → 5/4` · sûreté : **sûre**.

## M4 · La montée par le diminué

| | |
| --- | --- |
| Id | `montees/4-diminue-1-sur-5` |
| Statut | à valider |
| Sensations | Tension · Majesté · Épique |
| Moments | Montée · Fin |
| Niveau | piano : intermédiaire · guitare : avancé |

**Avant → après** : `G → A → D` devient `G – G#dim → D/A – A → D` · degrés
`4 → 5 → 1` devient `4 – #4dim → 1/5 – 5 → 1`.

**Pourquoi ça marche.** La basse monte demi-ton par demi-ton, G → G# → A.
G#dim7 garde B et D de G, et G# pousse vers A. Puis D/A (l'accord final, mais
sur A) retarde encore l'arrivée. Un son de grand cantique.

**Quand l'éviter.**
- Quand la mélodie chante G ou A pendant G#dim.
- Sur un tempo rapide ou un chant simple : trop d'accords pour la phrase.

**Au piano.** Main gauche : G – G# – A – A – D. Main droite : B-D-G, B-D-F,
A-D-F#, A-C#-E, A-D-F#.

**À la guitare.** G `320033` – G#dim7 `4x343x` – D/A `x00232` – A `x02220` –
D `xx0232`.

**Dans le répertoire** (`#4dim → 1/5` : 3 chants, en chinois) : 耶稣耶稣 (副歌,
en C : F#dim – C/G) · 圣灵的江河 (前奏, en F : Bdim – F/C) · 好喜欢与你在一起
(主歌 2, en Bb : Edim – Bb/F).

**Règle.** Portée : fin de section · motif `4 → 5 → 1` · remplacement
`4 – #4dim → 1/5 – 5 → 1` · sûreté : **à écouter**.

## M5 · Le break sur le 5

| | |
| --- | --- |
| Id | `montees/break` |
| Statut | à valider |
| Sensations | Tension · Surprise · Joie et élan |
| Moments | Montée |
| Niveau | piano : facile · guitare : facile · **à préparer avec l'équipe** |

**Avant → après** : `A → (refrain)` devient `A (un coup) – silence → (refrain)`.

**Pourquoi ça marche.** Tout le monde joue un seul coup sur A (ou Asus4), puis
se tait une mesure. Le silence est la tension maximale : quand le refrain
repart, c'est une explosion.

**Quand l'éviter.**
- Sans l'avoir répété avec le batteur et les chanteurs : un break raté
  s'entend beaucoup.
- Plus d'une fois par chant.

**Au piano.** Un accord de A plaqué, les deux mains, puis les mains en l'air.
Donne le départ du refrain d'un geste ou d'un regard.

**À la guitare.** Un coup sur A, puis étouffer les cordes avec la paume.

**Dans le répertoire** : ne se voit pas dans les partitions ; il se décide en
répétition.

**Règle.** Aucune : catalogue seul.
