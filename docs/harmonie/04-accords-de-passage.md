# 04 · Accords de passage

Un accord glissé **juste avant** un autre, pour le faire désirer. La plupart
sont des « 5 d'un autre accord » : comme A pousse vers D, F#7 pousse vers Bm,
D7 vers G, B7 vers Em, E7 vers A. Ils sortent un instant de la gamme : c'est ce
qui leur donne leur force.

Tout est écrit en D. `3 7` = accord majeur construit sur le 3e degré, avec
septième (F#7).

---

## P1 · Le 5 du 6m

| | |
| --- | --- |
| Id | `passage/5-du-6m` |
| Statut | à valider |
| Sensations | Tension · Surprise · Tendresse et nostalgie |
| Moments | Couplet · Refrain · Montée |
| Ressenti | élan · couleur (proposé) |
| Usage | couplet · pré-refrain · refrain (proposé) |
| Niveau | piano : intermédiaire · guitare : intermédiaire |

**Avant → après** : `D/F# → Bm` devient `F#7 → Bm` (ou `D → Bm` devient
`D – F#7 → Bm`) · degrés `1/3 → 6m` devient `3 7 → 6m`.

**Pourquoi ça marche.** F#7 contient A#, hors de la gamme de D, juste sous B :
il tire vers Bm comme C# tire vers D. Pendant un instant, Bm devient « la
maison ». Avec D/F# avant, la basse ne bouge même pas : seul l'accord change
au-dessus.

**Quand l'éviter.**
- **Quand la mélodie chante A** pendant F#7 : A contre A# frotte. A est une
  note très fréquente en D, d'où « à écouter ».

**Au piano.** Main gauche : F#. Main droite : A#-C#-E (ou E-A#-C#).

**À la guitare.** F#7 `242322`.

**Dans le répertoire** (`3 → 6m` : 36 chants, 4 fr, 32 zh) : *Je louerai
l'Éternel* (couplet : F# – Bm « Je raconterai toutes Tes merveilles ») ·
*Auprès de Dieu* (refrain, en A : C#7 – F#m7 « Je viens, je viens devant le
trône ») · *Né pour nous donner la vie* (refrain, en A : C#7 – F#m7) ·
住在你里面 (副歌 : F# – Bm) · 一生爱你 (副歌, en E : G# – C#m).

**Règle.** Portée : dans une section · motif `1/3 → 6m` ou `1 → 6m` ·
remplacement `3 7 → 6m` · sûreté : **à écouter**.

## P2 · Le 5 du 4

| | |
| --- | --- |
| Id | `passage/5-du-4` |
| Statut | à valider |
| Sensations | Joie et élan · Tension |
| Moments | Couplet · Refrain |
| Ressenti | élan (proposé) |
| Usage | couplet · refrain (proposé) |
| Niveau | piano : facile · guitare : facile |

**Avant → après** : `D → G` devient `D – D7 → G` · degrés `1 → 4` devient
`1 – 1 7 → 4`.

**Pourquoi ça marche.** D7 ajoute C naturel (hors gamme), qui descend d'un
demi-ton sur B, la tierce de G : on entend G arriver. Le son est chaleureux,
un peu gospel. C'est l'accord de passage le plus facile : on ajoute une note au
1.

**Quand l'éviter.**
- Quand la mélodie chante C# pendant D7 : C# contre C frotte.
- Sur un moment intime : D7 donne de l'élan, pas du recueillement.

**Au piano.** Main droite : D-F#-A puis C-F#-A (le D d'en haut descend sur C).
Main gauche : D.

**À la guitare.** D `xx0232` puis D7 `xx0212`.

**Dans le répertoire** (`1 7 → 4` : 22 chants, 3 fr, 19 zh) : *Le Fils de
Dieu* (refrain : « remplis-nous de Toi », D7 – GM7) · *Mon rédempteur vit*
(couplet, en E : E7 – A) · *Une flamme en moi* (couplet, en G : G7 – C) ·
一生爱你 (副歌, en E : E7 – A) · 何等恩典 (副歌, en G : G7 – C).

**Règle.** Portée : dans une section · motif `1 → 4` · remplacement
`1 – 1 7 → 4` · sûreté : **sûre**.

## P3 · Le 5 du 2m

| | |
| --- | --- |
| Id | `passage/5-du-2m` |
| Statut | à valider |
| Sensations | Tension · Joie et élan |
| Moments | Couplet · Refrain |
| Ressenti | élan (proposé) |
| Usage | couplet · refrain (proposé) |
| Niveau | piano : intermédiaire · guitare : intermédiaire |

**Avant → après** : `Bm → Em` devient `B7 → Em` · degrés `6m → 2m` devient
`6 7 → 2m`.

**Pourquoi ça marche.** B7, c'est Bm dont le D monte d'un demi-ton : D# (hors
gamme), qui tire vers E. On garde la basse B, on change une note, et Em arrive
comme une résolution.

**Quand l'éviter.**
- **Quand la mélodie chante D** pendant B7 : D contre D# frotte fort. D est la
  tonique, très fréquente.

**Au piano.** Main gauche : B. Main droite : A-D#-F# (au lieu de A-D-F#).

**À la guitare.** B7 `x21202`.

**Dans le répertoire** (`6 → 2m` : 11 chants, 1 fr, 10 zh) : *Grâce infinie*
(refrain, en E : C# – F#m « Sa grâce coule comme la pluie ») · 一颗谦卑的心
(副歌 : B7 – Em) · 你的同在 (主歌 : B7 – Em) · 一生敬拜你 (主歌, en C : A – Dm).

**Règle.** Portée : dans une section · motif `6m → 2m` · remplacement
`6 7 → 2m` · sûreté : **à écouter**.

## P4 · Le 5 du 5

| | |
| --- | --- |
| Id | `passage/5-du-5` |
| Statut | à valider |
| Sensations | Joie et élan · Lumière et espérance |
| Moments | Refrain · Montée |
| Ressenti | chaleureux · élan (proposé) |
| Usage | pré-refrain · refrain (proposé) |
| Niveau | piano : facile · guitare : facile |

**Avant → après** : `Em → A` devient `E7 → A` · degrés `2m → 5` devient
`2 7 → 5`.

**Pourquoi ça marche.** E7, c'est Em dont le G monte d'un demi-ton : G# (hors
gamme), qui tire vers A. Le 5 arrive avec plus d'élan, puis le 1. Un son de
cantique, joyeux.

**Quand l'éviter.**
- Quand la mélodie chante G pendant E7 : G contre G# frotte.
- Juste après avoir essayé S1 ou S3 sur le même passage : choisir l'une des
  trois idées.

**Au piano.** Main gauche : E. Main droite : D-G#-B.

**À la guitare.** E7 `020100`.

**Dans le répertoire** (`2 → 5` : 31 chants, 5 fr, 26 zh) : *Notre Père*
(refrain, en F : G – C « Sur toute la terre ») · *Que Ton Nom résonne en ce
lieu* (pont, en C : D – G) · *Noël est arrivé* (couplet, en Bb : C – F) ·
充满在这里 (副歌, en A : B – E) · 你的爱不离不弃 (副歌, en A : B7 – E).

**Règle.** Portée : dans une section · motif `2m → 5` · remplacement
`2 7 → 5` · sûreté : **à écouter**.

## P5 · Le diminué de passage

| | |
| --- | --- |
| Id | `passage/diminue` |
| Statut | à valider |
| Sensations | Tension · Tendresse et nostalgie |
| Moments | Couplet · Montée |
| Ressenti | mélancolique · élan (proposé) |
| Usage | couplet · pré-refrain (proposé) |
| Niveau | piano : intermédiaire · guitare : intermédiaire |

**Avant → après** : `D → Em` devient `D – D#dim → Em` · degrés `1 → 2m`
devient `1 – #1dim → 2m`.

**Pourquoi ça marche.** La basse monte d'un demi-ton, D → D# → E. D#dim7
(D#-F#-A-C) garde F# et A de l'accord de D : il glisse sans heurt, et D#
pousse vers E. Un son de cantique, élégant.

**Quand l'éviter.**
- Quand la mélodie tient D pendant D#dim : frottement fort.
- Sur un tempo rapide : trop court pour s'entendre.

**Au piano.** Main gauche : D# (entre D et E). Main droite : F#-A-C.

**À la guitare.** D#dim7 `xx1212`.

**Dans le répertoire** : pas encore de `1 – #1dim – 2m` exact ; des accords
diminués apparaissent dans 19 chants chinois, par exemple 住在你里面 (副歌 :
G#dim – Em), 何等恩典 (副歌, en G : G#dim), 吹起复兴的风 (桥段, en C : F#dim).

**Règle.** Portée : dans une section · motif `1 → 2m` · remplacement
`1 – #1dim → 2m` · sûreté : **à écouter**.

## P6 · Le 7m7b5 – 3 7 vers le 6m

| | |
| --- | --- |
| Id | `passage/2-5-mineur` |
| Statut | à valider |
| Sensations | Gravité et recueillement · Tension · Tendresse et nostalgie |
| Moments | Pont · Couplet |
| Ressenti | mélancolique · élan (proposé) |
| Usage | couplet · pré-refrain (proposé) |
| Niveau | piano : avancé · guitare : avancé |

**Avant → après** : `A → Bm` devient `C#m7b5 – F#7 → Bm` · degrés `5 → 6m`
devient `7m7b5 – 3 7 → 6m`.

**Pourquoi ça marche.** C'est le « 2m7 – 5 – 1 » de S1, mais **vers Bm** et en
mineur : C#m7b5 prépare, F#7 tend, Bm résout. Plus sombre, plus dramatique :
une vraie parenthèse en mineur.

**Quand l'éviter.**
- Quand la mélodie chante D pendant C#m7b5, ou A pendant F#7.
- Sur un passage court : il faut au moins deux temps par accord.

**Au piano.** C#m7b5 : main gauche C#, main droite E-G-B. F#7 : main gauche F#,
main droite E-A#-C#. Les deux mains bougent peu.

**À la guitare.** C#m7b5 `x4545x` ; F#7 `242322` ; Bm `x24432`.

**Dans le répertoire** (`7m7b5` : 4 chants, en chinois) : 你的同在 (前奏 :
C#m7(b5)) · 我需要有你在我生命中 (主歌 2, en C : Bm7b5) · 敬拜的心 (主歌, en
F : Em7b5).

**Règle.** Portée : Pont, Couplet · motif `5 → 6m` · remplacement
`7m7b5 – 3 7 → 6m` · sûreté : **à écouter**.

## P7 · Le 3m qui devient majeur

| | |
| --- | --- |
| Id | `passage/3-majeur` |
| Statut | à valider |
| Sensations | Tension · Tendresse et nostalgie |
| Moments | Couplet · Refrain |
| Ressenti | élan · mélancolique (proposé) |
| Usage | couplet · refrain (proposé) |
| Niveau | piano : facile · guitare : intermédiaire |

**Avant → après** : `G → A → F#m → Bm` devient `G → A → F# → Bm` · degrés
`4 → 5 → 3m → 6m` devient `4 → 5 → 3 → 6m`.

**Pourquoi ça marche.** Une seule note change : le A de F#m monte d'un
demi-ton sur A#. Cette note veut monter sur B, la base de Bm : F# devient le
5 du 6m, et la chute vers Bm devient une petite cadence en mineur. Là où P1
part du 1 (`D/F# → Bm`), cette fiche part d'un 3m déjà écrit dans la grille.

**Quand l'éviter.**
- Quand la mélodie chante A (sans dièse) sur ce temps : il frotte contre A#.
- Quand le chant reste lumineux de bout en bout : le 3m est plus calme.

**Variante.** `F#7` (avec E) pour tirer encore plus vers Bm (P1) ; `F# → G`
(`3 → 4`) : A# monte sur B, F# monte sur G.

**Au piano.** Main gauche : G, A, F#, B. Main droite : B-D-G, puis A-C#-E,
puis A#-C#-F#, puis B-D-F#.

**À la guitare.** F# en barré 2e case (`244322`) ; F#7 en `242322`.

**Dans le répertoire** (`3 → 6m` dans une ligne : 32 chants) : *Je louerai
l'Éternel* (couplets, en D : G – A – F# – Bm) · *Je loue Ton Nom, Éternel*
(refrain, en G : C – D – B7 – Em, avec la 7 : voir P1) · 一同齐声宣扬 (副歌, en A : D – C# – F#m) ·
十字架是我的荣耀 (副歌, en F : F – A7 – Bb, le `3 → 4`).

**Règle.** Aucune : catalogue seul (une règle de suggestion
se proposera à part).

## P8 · Le 2m7b5 de passage, avant le 1

| | |
| --- | --- |
| Id | `passage/2m7b5` |
| Statut | à valider |
| Sensations | Tendresse et nostalgie · Douceur et intimité |
| Moments | Fin · Couplet |
| Ressenti | mélancolique · chaleureux (proposé) |
| Usage | fin · couplet (proposé) |
| Niveau | piano : intermédiaire · guitare : intermédiaire |

**Avant → après** : `Em7 → A → D` devient `Em7 – Em7b5/A → D` · degrés
`2m7 → 5 → 1` devient `2m7 – 2m7b5/5 → 1`.

**Pourquoi ça marche.** Em7b5, c'est E-G-Bb-D : le B de Em7 descend sur Bb,
puis sur le A de D. Une ligne chromatique (B, Bb, A) au milieu des accords.
Avec la basse A, l'accord fait office de 5, assombri : Bb vient de D mineur,
un instant d'ombre juste avant la lumière du 1.

**Quand l'éviter.**
- Quand la mélodie chante B sur cet accord : il frotte contre le Bb.
- Dans un refrain énergique : l'ombre ralentit l'élan.

**Variante.** Le préparer par le 5 du 2m (P3) : `B7 → Em7 – Em7b5/A → D`,
toute la grille descend. Sans la basse A : `Em7 – Em7b5 → D/F#`.

**Au piano.** Main gauche : E, puis A, puis D. Main droite : D-G-B, puis
D-G-Bb (un seul doigt descend), puis D-F#-A.

**À la guitare.** Em7 en `022030`, puis Em7b5 en `012030` (un doigt descend d'une
case sur la 5e corde, B → Bb ; la basse A se laisse au bassiste ou au piano), puis D.

**Dans le répertoire** (en chinois) : 爱的约定 (副歌 2, en C : Dm7 – Dm7b5/G –
Cmaj9) ; plus loin du motif, la basse sur le b5 : 唯有耶稣 (副歌, en G :
Am – Am7b5/Eb – G/D, basse Eb → D).

**Règle.** Aucune : catalogue seul (une règle de suggestion
se proposera à part).
