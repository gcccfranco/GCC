# 09 · Transitions entre deux chants

Passer d'un chant à l'autre **sans silence gênant**. Dans l'app, ces idées
apparaissent dans les « Idées d'harmonie » du chant qui précède, dans la
setlist, en lecture seule : le site connaît la tonalité des deux chants et
choisit la fiche qui correspond (lot H4).

Tout est écrit en partant d'un chant en D. Pas d'exemples tirés du répertoire :
les transitions vivent entre les chants (T7 cite seulement les chants notés en
6/8 ou 12/8). T7 change de mesure, pas de tonalité : le site ne la choisit pas
seul, elle vit dans le catalogue.

---

## T1 · Même tonalité : enchaîner sans couper

| | |
| --- | --- |
| Id | `transitions/meme-tonalite` |
| Statut | à valider |
| Sensations | Repos · Douceur et intimité |
| Moments | Transition |
| Ressenti | chaleureux (proposé) |
| Usage | transition (proposé) |
| Niveau | piano : facile · guitare : facile |

**Avant → après** : fin sur `D`, silence, intro du chant suivant devient fin
sur `D`, **boucle `D – G/D`** (F3) pendant la transition, puis le chant
suivant démarre.

**Pourquoi ça marche.** La tonalité ne change pas : il suffit de ne pas
s'arrêter. La boucle laisse le temps à la présidence de parler ou de prier,
et le chant suivant sort de la même couleur.

**Quand l'éviter.**
- Quand les deux chants ont des caractères opposés (célébration puis
  recueillement) : un vrai silence peut être juste.

**Au piano.** Baisse le volume pendant la boucle. Le chant suivant repart
quand la présidence fait signe.

**À la guitare.** D `xx0232` ↔ G/D `xx0433`, en arpèges.

**Règle.** Calculée dans la setlist : proposée quand le chant suivant est dans
la même tonalité.

## T2 · Vers la tonalité du 4

| | |
| --- | --- |
| Id | `transitions/vers-le-4` |
| Statut | à valider |
| Sensations | Repos · Joie et élan |
| Moments | Transition |
| Ressenti | chaleureux · élan (proposé) |
| Usage | transition (proposé) |
| Niveau | piano : facile · guitare : facile |

**Avant → après** : chant en D, puis chant en G : finir sur `D` (ou `D7`),
et le chant en G arrive tout seul.

**Pourquoi ça marche.** D est le « 5 » de G : un chant qui finit sur D
**annonce** déjà G. D7 renforce l'appel (voir P2).

**Quand l'éviter.**
- Presque jamais : c'est la transition la plus naturelle.

**Au piano.** Dernier accord : D7 (main droite C-F#-A), puis G.

**À la guitare.** D7 `xx0212`, puis G `320033`.

**Règle.** Calculée dans la setlist : proposée quand le chant suivant est une
quarte plus haut (D → G).

## T3 · Vers la tonalité du 5

| | |
| --- | --- |
| Id | `transitions/vers-le-5` |
| Statut | à valider |
| Sensations | Lumière et espérance · Joie et élan |
| Moments | Transition |
| Ressenti | chaleureux · élan (proposé) |
| Usage | transition (proposé) |
| Niveau | piano : facile · guitare : facile |

**Avant → après** : chant en D, puis chant en A : `D → E (ou Esus4 – E) →
A`.

**Pourquoi ça marche.** D est le « 4 » de A. Il suffit d'ajouter E, le « 5 »
de A : D – E – A est un enchaînement que tout le monde connaît.

**Quand l'éviter.**
- Quand le chant suivant commence sur un autre accord que A : finir la
  transition sur E et laisser le chant démarrer.

**Au piano.** Main gauche : D – E – A. Main droite : D-F#-A, E-G#-B, E-A-C#.

**À la guitare.** D `xx0232` – Esus4 `022200` – E `022100` – A `x02220`.

**Règle.** Calculée dans la setlist : proposée quand le chant suivant est une
quinte plus haut (D → A).

## T4 · Un ton plus haut

| | |
| --- | --- |
| Id | `transitions/ton-plus-haut` |
| Statut | à valider |
| Sensations | Épique · Joie et élan · Lumière et espérance |
| Moments | Transition |
| Ressenti | élan (proposé) |
| Usage | transition (proposé) |
| Niveau | piano : facile · guitare : intermédiaire |

**Avant → après** : chant en D, puis chant en E : `D → B7 → E` (ou
`D → A/B → E`, plus doux).

**Pourquoi ça marche.** Comme D1 : B7 est le « 5 » de E. Entre deux chants,
cette montée donne de l'élan au second.

**Quand l'éviter.**
- Si le second chant est plus calme que le premier : prendre `A/B` (D4), ou
  un vrai silence.

**Au piano.** B7 : main gauche B, main droite A-D#-F#.

**À la guitare.** B7 `x21202` ou A/B `x22220`, puis E `022100`.

**Règle.** Calculée dans la setlist : proposée quand le chant suivant est un
ton plus haut (D → E).

## T5 · Un ton plus bas

| | |
| --- | --- |
| Id | `transitions/ton-plus-bas` |
| Statut | à valider |
| Sensations | Douceur et intimité · Repos |
| Moments | Transition |
| Ressenti | chaleureux (proposé) |
| Usage | transition (proposé) |
| Niveau | piano : intermédiaire · guitare : intermédiaire |

**Avant → après** : chant en D, puis chant en C : `D → Dm7 – G7 → C`.

**Pourquoi ça marche.** La basse reste sur D, mais l'accord devient mineur :
Dm7 est **déjà le 2m7 de C**. Puis G7 (5 de C) et C. On descend d'un ton en
douceur, sans que personne ne sente la marche.

**Quand l'éviter.**
- Sur une transition courte : il faut au moins deux mesures.

**Au piano.** Main gauche : D – G – C. Main droite : C-F-A (Dm7), B-D-F (G7),
C-E-G.

**À la guitare.** Dm7 `xx0211` – G7 `320001` – C `x32010`.

**Règle.** Calculée dans la setlist : proposée quand le chant suivant est un
ton plus bas (D → C).

## T6 · Tonalité éloignée : la note commune

| | |
| --- | --- |
| Id | `transitions/note-commune` |
| Statut | à valider |
| Sensations | Suspendu et planant · Surprise |
| Moments | Transition |
| Ressenti | couleur (proposé) |
| Usage | transition (proposé) |
| Niveau | piano : avancé · guitare : avancé |

**Avant → après** : chant en D, puis chant en Bb : fin sur `D`, **une seule
note tenue** (D), puis `F7 → Bb`.

**Pourquoi ça marche.** Entre deux tonalités éloignées, on cherche une note
présente dans les deux : ici D, fondamentale de D et tierce de Bb. Tenue seule,
elle fait le pont. Puis le « 5 » de la nouvelle tonalité (F7) installe Bb.

**Quand l'éviter.**
- Quand aucune note commune ne sonne bien : un silence net vaut mieux qu'une
  transition hésitante.

**Au piano.** Laisse D seul en haut de la main droite, puis pose F7 (main
gauche F, main droite Eb-A-C), puis Bb.

**À la guitare.** Laisse sonner la corde de ré à vide, puis F7 `131211`, puis
Bb `x13331`.

**Règle.** Calculée dans la setlist : proposée quand aucune des fiches T1 à T5
ne correspond ; le site cherche la note commune et le 5 de la nouvelle
tonalité.

## T7 · D'un chant en 6/8 vers un chant en 4/4

| | |
| --- | --- |
| Id | `transitions/6-8-vers-4-4` |
| Statut | à valider |
| Sensations | Repos · Joie et élan |
| Moments | Transition |
| Ressenti | chaleureux · élan (proposé) |
| Usage | transition (proposé) |
| Niveau | piano : intermédiaire · guitare : intermédiaire · **à préparer avec l'équipe** |

**Avant → après** : fin du chant en 6/8 sur `D`, silence, décompte du chant
en 4/4 devient fin sur `D` tenu, puis **la noire pointée du 6/8 devient la
noire du 4/4** : on garde la même pulsation (les deux grands temps de la
mesure en 6/8) et on la compte « 1 2 3 4 » ; le chant suivant part sur ce
compte.

**Pourquoi ça marche.** Un 6/8 se sent en deux grands temps, chacun partagé en
trois. Si l'on garde ce grand temps comme nouvelle noire, le pied de
l'assemblée ne change pas de vitesse : seule la subdivision passe de trois à
deux. Le chant suivant arrive sans coup de frein ni d'accélérateur. Un 12/8
se sent en quatre grands temps : le passage au 4/4 est encore plus direct.
Si la tonalité change aussi, enchaîner ensuite avec T1 à T6.

**Quand l'éviter.**
- Quand le chant en 4/4 est bien plus rapide ou plus lent : garder la
  pulsation donnerait un faux tempo. Faire un vrai arrêt.
- Sans le batteur ou celui qui donne les départs : il compte les quatre temps
  à voix haute ou au charleston.

**Au piano.** Sur la dernière mesure en 6/8, la main gauche joue seulement les
deux grands temps (D, D). Puis des noires régulières sur D, au même pas,
jusqu'au départ du chant suivant.

**À la guitare.** Dernière mesure en 6/8 : deux coups larges, sur le 1 et sur
le 4. Puis des coups réguliers sur D, au même pas, en comptant 1 2 3 4.

**Dans le répertoire** : 为我而来 (en C, 6/8) · 十字架 (en E, 6/8) · 活出爱 (en
C, 12/8).

**Règle.** Aucune : catalogue seul.
