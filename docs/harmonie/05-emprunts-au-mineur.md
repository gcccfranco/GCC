# 05 · Emprunts au mineur

On **emprunte** un accord à la tonalité voisine en mineur (D mineur quand on
est en D) : Gm, Bb, C, F. Ces accords sortent de la gamme et donnent d'un coup
de l'émotion : tendresse, grandeur, épopée. Puis on revient à la maison.

Tout est écrit en D. `b6` = Bb, `b7` = C, `b3` = F, `4m` = Gm.

---

## E1 · Le 4 mineur avant le 1

| | |
| --- | --- |
| Id | `emprunts/4m-avant-1` |
| Statut | à valider |
| Sensations | Tendresse et nostalgie · Douceur et intimité |
| Moments | Fin · Refrain |
| Niveau | piano : facile · guitare : intermédiaire |

**Avant → après** : `G → D` devient `G – Gm → D` · degrés `4 → 1` devient
`4 – 4m → 1`.

**Pourquoi ça marche.** Gm, c'est G dont le B descend d'un demi-ton : Bb, qui
descend encore sur A, la quinte de D. Une ligne qui soupire (B, Bb, A), une
émotion qui passe, puis la maison.

**Quand l'éviter.**
- Quand la mélodie chante B pendant Gm : B contre Bb frotte.
- Dans un chant tout en joie : Gm peut sonner mélancolique à contretemps.

**Au piano.** Main droite : G-B-D, puis G-Bb-D (un doigt descend), puis
F#-A-D. Main gauche : G, G, D.

**À la guitare.** G `320033` – Gm `xx5333` (ou barré `355333`) – D `xx0232`.

**Dans le répertoire** (`4 → 4m` : 7 chants ; `4m → 1` : 4 chants) :
*Grâce infinie* (refrain, en E : A – Am – E « Sa grâce coule comme la pluie »)
· 一切歌颂赞美 (副歌, en E : A – Am – E) · 唯独依靠你 (副歌, en E : A – Am – E)
· 看见复兴 (副歌, en A : Dm – A).

**Règle.** Portée : fin de section · motif `4 → 1` · remplacement
`4 – 4m → 1` · sûreté : **à écouter**.

## E2 · La montée épique b6 – b7 – 1

| | |
| --- | --- |
| Id | `emprunts/b6-b7-1` |
| Statut | à valider |
| Sensations | Épique · Majesté · Joie et élan |
| Moments | Fin · Montée · Refrain |
| Niveau | piano : facile · guitare : intermédiaire |

**Avant → après** : `A → D` (toute fin) devient `Bb – C → D` · degrés
`5 → 1` devient `b6 – b7 → 1`.

**Pourquoi ça marche.** Bb et C viennent de D mineur. Leurs basses montent
Bb → C → D par tons entiers, comme une marche vers le sommet, et D majeur
arrive en pleine lumière après deux accords « d'ailleurs ». C'est le grand
final des musiques de film.

**Quand l'éviter.**
- Quand la mélodie chante F# ou B pendant Bb, ou C# pendant C : à placer quand
  la voix tient D ou se tait (fin instrumentale).
- Sur une fin douce : c'est un final de grandeur, pas de recueillement.

**Au piano.** Main gauche : Bb – C – D, en octaves si tu veux de la puissance.
Main droite : Bb-D-F, C-E-G, D-F#-A.

**À la guitare.** Bb `x1333x` – C `x32010` – D `xx0232`. En rythmique large,
un accord par temps fort.

**Dans le répertoire** (`b6 – b7 – 1` : 2 chants, en chinois) : 为我而来
(桥段, en C : Ab – Bb – C) · 明亮晨星 (前奏, en F : Db – Eb – F).

**Règle.** Portée : dernière occurrence, toute fin du chant · motif `5 → 1`
final · remplacement `b6 – b7 → 1` · sûreté : **à écouter**.

## E3 · Le b7 qui ouvre

| | |
| --- | --- |
| Id | `emprunts/b7-4-1` |
| Statut | à valider |
| Sensations | Joie et élan · Épique · Majesté |
| Moments | Refrain · Intro · Fin |
| Niveau | piano : facile · guitare : facile |

**Avant → après** : `G → D` devient `C – G → D` · degrés `4 → 1` devient
`b7 – 4 → 1`.

**Pourquoi ça marche.** C (hors gamme) descend vers G, qui descend vers D :
deux fois le même mouvement de « retour à la maison », large, sans la tension
de A. Un son ouvert, un peu celtique ou rock.

**Quand l'éviter.**
- Quand la mélodie chante C# pendant C : C# est la note qui mène à D, souvent
  chantée juste avant la fin.

**Au piano.** Main gauche : C – G – D. Main droite : C-E-G, B-D-G, A-D-F#.

**À la guitare.** C `x32010` – G `320033` – D `xx0232`.

**Dans le répertoire** (`b7 → 4` : 3 chants ; `b7 → 1` : 3 chants) : *Au nom
de Jésus* (refrain : « Christ ressuscité vit en moi », C – G ; intro : C – D)
· *Fidèle Loyal* (refrain, en C : Bb – F) · 耶和华行了大事 (桥段, en Bb :
Ab – Eb).

**Règle.** Portée : fin de ligne · motif `4 → 1` · remplacement `b7 – 4 → 1`
· sûreté : **à écouter**.

## E4 · Le b3 de passage

| | |
| --- | --- |
| Id | `emprunts/b3-de-passage` |
| Statut | à valider |
| Sensations | Épique · Joie et élan |
| Moments | Intro · Montée |
| Niveau | piano : facile · guitare : intermédiaire |

**Avant → après** : `D → G` devient `D – F → G` · degrés `1 → 4` devient
`1 – b3 → 4`.

**Pourquoi ça marche.** F (hors gamme) glisse entre D et G : la basse monte
D → F → G, avec un accord « bluesy » au milieu. Énergique, un peu rock.

**Quand l'éviter.**
- **Quand la mélodie chante F#** pendant F : frottement fort, et F# est très
  fréquent en D. À réserver aux passages instrumentaux (intro, interlude).

**Au piano.** Main gauche : D – F – G. Main droite : D-F#-A, C-F-A, B-D-G.

**À la guitare.** D `xx0232` – F `xx3211` – G `320033`.

**Dans le répertoire** : aucun chant ne l'utilise encore.

**Règle.** Portée : Intro, Interlude · motif `1 → 4` · remplacement
`1 – b3 → 4` · sûreté : **à écouter**.

## E5 · Le b6 à la place du 4 en fin

| | |
| --- | --- |
| Id | `emprunts/b6-pour-4` |
| Statut | à valider |
| Sensations | Majesté · Émerveillement · Épique |
| Moments | Fin |
| Niveau | piano : facile · guitare : intermédiaire |

**Avant → après** : `G → D` (toute fin) devient `Bb → D` · degrés `4 → 1`
devient `b6 → 1`.

**Pourquoi ça marche.** Bb garde D, et ses deux autres notes montent ou
descendent d'un demi-ton pour arriver sur D : Bb → A, F → F#. La lumière
s'ouvre, comme un rideau qui se lève sur l'accord final.

**Quand l'éviter.**
- Quand la mélodie chante B pendant Bb : frottement fort.
- Sur une fin intime : l'effet est grandiose.

**Au piano.** Main gauche : Bb puis D. Main droite : Bb-D-F puis A-D-F#.

**À la guitare.** Bb `x1333x` puis D `xx0232`.

**Dans le répertoire** : aucun chant ne l'utilise encore.

**Règle.** Portée : dernière occurrence, toute fin du chant · motif `4 → 1`
final · remplacement `b6 → 1` · sûreté : **à écouter**.
